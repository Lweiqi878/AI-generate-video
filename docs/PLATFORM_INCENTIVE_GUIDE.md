# 游戏内容激励计划查找与投稿检查

> 状态日期：2026-08-31。平台活动会按账号、地区和时间变化；账号内正式任务卡与当期完整规则始终优先于网页搜索结果。

## 先分清三件事

1. **普通话题**：能参与讨论或获得自然流量，不等于现金激励。
2. **平台活动页**：可能只有曝光、抽奖或榜单奖励，也不一定按播放量结算。
3. **正式激励任务**：账号内可报名或领取，写明期限、资格、投稿要求、结算指标与奖励方式。

没有正式任务卡时，不要因为搜到 `#绝区零创作者激励计划` 等话题，就把视频文件夹或投稿文案标成“已参与激励”。

## 抖音

- 在抖音 App 搜索并进入 **游戏发行人计划** 小程序，再从“任务/可接任务”中按游戏名搜索。
- 也可从 [游戏发行人计划官网](https://www.gamepublisher.cn/) 了解机制；最终仍以当前抖音账号内能否领取任务为准。
- 找不到《绝区零》任务通常意味着当前账号没有可领取的正式任务，可能是活动未开放、已结束、定向开放或账号条件不符，并不代表搜索方法有问题。
- 发布前逐项核对：必须挂载的任务组件、指定话题、时长、横竖屏、原创要求、AI内容规则、结算口径和截止时间。

## 小红书

- 在 App 进入 **我 → 创作中心 → 活动中心**，按游戏名、官方账号和活动话题查找。
- 同时检查游戏官方账号的置顶笔记与官方话题页；部分活动只对特定账号展示，桌面网页可能看不到。
- [小红书创作服务平台](https://creator.xiaohongshu.com/) 用于发布和管理内容，但是否存在激励任务仍以 App 账号内活动页为准。
- 若只有话题而没有报名页、规则与奖励说明，就按普通投稿处理。

## 哔哩哔哩

- 在创作中心活动页、游戏分区活动页或游戏官方账号动态中找当期计划。
- 《绝区零》当前公开的 [3.1版本UP主激励计划](https://www.bilibili.com/v/topic/detail/?topic_id=1200649&topic_name=%E7%BB%9D%E5%8C%BA%E9%9B%B6UP%E4%B8%BB%E6%BF%80%E5%8A%B1%E8%AE%A1%E5%88%92) 显示截至 2026-09-08 23:59；公开页没有明确确认生成式AI内容资格，因此本仓库相关作品继续标为“资格待核验”。
- B站的“UP主激励计划”不会自动延伸到抖音或小红书，三个平台必须分别报名和核验。

## 投稿前30秒检查

- [ ] 账号内确实存在可领取/已报名的正式任务卡。
- [ ] 截止时间、账号资格和内容分区均符合。
- [ ] 规则明确接受AI生成或AI辅助内容；不明确就按普通投稿并保留AI标识。
- [ ] 使用了任务要求的挂载、话题、标题格式或投稿入口。
- [ ] 游戏素材、音乐、配音与第三方图像的授权范围清楚。
- [ ] 记录任务页截图、规则版本和投稿时间，方便后续申诉与结算。

## 本项目采用的内容方法

- 首秒先给冲突或结果，观众不用猜“这是在讲什么”。
- 用玩家能立刻识别的具体处境，而不是随机物体变形：安比只剩一根薯条、开拓者执着最后一个垃圾桶。
- 10–15秒内完成“起因—升级—回报”，结尾兑现标题，而不是只展示模型动态效果。
- 抖音标题偏冲突与结果，小红书标题偏感受或提问，B站标题补齐角色、故事和AI短片类型。
- 广告感越低越好；任务要求通过正确入口、挂载和标签完成，不把口播硬塞进故事。
